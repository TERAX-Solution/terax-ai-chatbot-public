## Hinweise für Autoren

- Sprache: einfaches Deutsch, Anrede „Sie“, keine Entwickler-Begriffe.
- Die Plugin-Oberfläche gibt es auf Deutsch (`languages/admin-de_DE.json`). Bezeichnungen aus der Oberfläche stehen **fett** und müssen genau so heißen wie am Bildschirm. Ändern Sie eine Übersetzung in der JSON-Datei, passen Sie die Seiten an.
- Screenshots gehören nach `docs/client/img/` und sollen die deutsche Oberfläche zeigen. Sie fehlen noch, weil die Oberfläche noch nicht übersetzt ist.
- Offen für die Prüfung: grobe Monatskosten je Anbieter in Seite 03 (siehe Kommentar im Text) und die Abgrenzung der Tarife (Seite 01), die dem Vertrag entsprechen muss.
- Die Datenschutzseite ist eine Erklärung der Einstellungen, keine Rechtsberatung. Interne Entwurfsnotizen zum Thema: [`docs/DATENSCHUTZ-PRAXEN.md`](../DATENSCHUTZ-PRAXEN.md).
