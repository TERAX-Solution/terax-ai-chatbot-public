# Terminbuchung

Der Assistent bucht selbst keine Termine. Wenn ein Besucher einen Termin wünschen, zeigt er einen Knopf, der Ihre bestehende Online-Terminbuchung öffnet (z. B. Dr. Flex, Doctolib oder Calendly). So bleibt Ihre Terminverwaltung unverändert.

Zeigt der Assistent den Knopf, steht darunter keine Quellenangabe, damit der Knopf im Vordergrund bleibt. Die Zahl der Klicks sehen Sie im Dashboard unter **Klicks auf Terminbuchung**.

## Buchungslink finden

Den Link finden Sie in Ihrem Buchungssystem:

- **Dr. Flex:** der öffentliche Buchungslink Ihrer Praxis (meist eine Adresse mit `dr-flex.de`).
- **Doctolib:** das öffentliche Profil Ihrer Praxis auf `doctolib.de`. Kopieren Sie die Adresse aus dem Browser, wenn Sie Ihr Profil geöffnet haben.
- **Calendly:** die Adresse Ihrer Buchungsseite, z. B. `https://calendly.com/ihre-praxis`.
- **Andere Systeme:** der Link, den Sie auch Patienten schicken würden. Er muss ohne Anmeldung erreichbar sein.

Testen Sie den Link in einem privaten Browserfenster: Er muss ohne Anmeldung die Terminauswahl zeigen.

## Im Plugin eintragen

1. **AI Assistant → Einstellungen → Terminbuchung**
2. **Buchungsknopf einschalten** einschalten.
3. Bei **Buchungssystem** Ihr System wählen: **Dr. Flex**, **Doctolib**, **Calendly** oder **Eigene URL**.
4. Den Link bei **Buchungs-URL** eintragen. Das graue Beispiel im Feld zeigt die erwartete Form.
5. Bei **Beschriftung des Knopfes** den Text des Knopfes festlegen, z. B. „Online-Termin buchen“.
6. Bei **Öffnen in** wählen, wie sich die Buchung öffnet (siehe unten).
7. **Änderungen speichern** klicken.

Der Knopf erscheint dann bei Terminwünschen im Chat und oben im Chat-Fenster als Kalender-Symbol.

## Neuer Tab oder Popup?

- **Neuer Tab** (Voreinstellung): Die Buchung öffnet sich in einem neuen Browser-Tab. Das funktioniert mit jedem System.
- **Popup über der Seite**: Die Buchung öffnet sich in einem Fenster über Ihrer Website.

Manche Buchungssysteme erlauben es nicht, in eine fremde Seite eingebettet zu werden. Bleibt das Popup leer oder weiß, wählen Sie **Neuer Tab**.

## Ohne Buchungslink

Ist kein Link hinterlegt, antwortet der Assistent, dass eine Online-Buchung nicht möglich ist, und verweist auf Ihre Telefonnummer oder E-Mail-Adresse (siehe **Einstellungen → Assistent**). Tragen Sie diese Kontaktdaten deshalb immer ein.
